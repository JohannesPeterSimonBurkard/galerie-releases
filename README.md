# Galerie – Updates

Hier liegen die fertigen Versionen der Galerie-App (Android 14 oder neuer). Der Quellcode ist nicht öffentlich.

## Einrichten (einmalig)

1. **Obtainium installieren** – eine kleine App, die nach Updates sucht:
   [github.com/ImranR98/Obtainium/releases](https://github.com/ImranR98/Obtainium/releases) → bei der neuesten Version die Datei mit **`arm64-v8a`** im Namen herunterladen und öffnen.
   Fragt Android nach „Unbekannte Apps installieren“: für den Browser bzw. Dateimanager erlauben.
2. In Obtainium unten auf **„Hinzufügen“** (bzw. „Add App“) tippen und als Adresse eintragen:
   ```
   https://github.com/JohannesPeterSimonBurkard/galerie-releases
   ```
   → **Hinzufügen**.
3. Bei „Galerie“ auf **Installieren** tippen. Obtainium darf dafür einmal „Unbekannte Apps installieren“.
   Falls Google Play Protect warnt („Unbekannte App“): **Weitere Details → Trotzdem installieren**.

## Updates

Obtainium sucht regelmäßig selbst nach neuen Versionen und meldet sich mit einer Benachrichtigung. Dann in Obtainium auf **Aktualisieren** tippen. Einstellungen und Anmeldung bleiben erhalten.

Ohne Obtainium: unter [Releases](https://github.com/JohannesPeterSimonBurkard/galerie-releases/releases/latest) die neueste `Galerie-….apk` herunterladen und öffnen.
